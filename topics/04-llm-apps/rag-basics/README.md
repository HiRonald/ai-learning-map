# RAG 基础：先查再答

> 状态：draft · 轨道：LLM Apps · 难度：L2

## 要解决什么问题

参数里装不下、也更新不及时的知识，如何在回答前 **检索** 再生成，而不是指望模型「背下来」？

## 直觉

把文档切块 → 做成可检索索引 → 问句召回相关片段 → 拼进提示让模型写答案。新鲜度与私有数据，优先放在检索层，而不是反复预训练。

**和 Memory 的差别**：RAG 查的是「知识库文档」；长期/会话 Memory 记的是「用户与任务状态」。Agent 常两者都要，但不要混成一个词——细节在 [Agent 基础](../agents-basics/)。

## 结构 / 公式

1. 索引 / 检索 / 生成三段式。
2. Embedding 检索与关键词检索的直觉对比；生产里常见 **hybrid + rerank**（点到职责即可）。
3. 失败模式一瞥：召回错、上下文塞爆、过期文档——评测落到 [LLMOps](../../05-ai-infra/llmops-observability/)。
