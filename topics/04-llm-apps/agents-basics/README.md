# Agent 基础：工具循环

> 状态：draft · 轨道：LLM Apps · 难度：L2

## 要解决什么问题

单次问答不够时，如何让模型在「思考 → 选工具 → 观察结果 → 再决策」的循环里完成多步任务？

## 直觉

把 LLM 当成决策器，而不是终点打印机。工具（搜索、代码、API、日历……）是手；观察是眼；循环是工作方式。

与 [具身 Sense-Plan-Act](../../06-embodied/sense-plan-act/)：这里的「环境」主要是软件 API；那边是物理/仿真世界。模式相似，约束不同。
