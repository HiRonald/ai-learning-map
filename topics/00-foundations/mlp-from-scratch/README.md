# 从零实现 MLP（XOR）

> 状态：published · 轨道：Foundations · 难度：L1 · 语言：C++

## 要解决什么问题

不依赖任何深度学习框架，手写一个可训练的多层感知机，完整走通：

**前向传播 → 损失 → 反向传播 → 参数更新**

并用经典的 **XOR** 问题验证这条链路是对的。

## 直觉

线性模型画不出 XOR 的分界线；加一层非线性隐藏层后，网络可以先把输入「扭」到更好分隔的空间，再做分类。

本主题关心的不是刷准确率，而是你能指着代码说出：梯度从损失回到每一层权重时经过了哪些步骤。

## 结构

网络：`2 → 4 → 1`，隐藏层与输出层均为 `sigmoid`，损失为 MSE。

形状约定（行样本）：

| 张量 | 形状 |
|------|------|
| 输入 `X` | `(batch, in)` |
| 权重 `W` | `(in, out)` |
| 偏置 `b` | `(1, out)` |
| 输出 `\hat{Y}` | `(batch, out)` |

一层前向：`Z = XW + b`，`A = f(Z)`。输出层单独配置激活（XOR 用 sigmoid 把输出压到 `(0,1)`）。

更细的公式、实现踩坑与模块说明见 [notes.md](./notes.md)。
