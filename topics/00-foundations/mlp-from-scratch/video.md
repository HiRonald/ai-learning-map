# 视频大纲：从零实现 MLP（XOR）

目标时长：8–12 分钟

## 钩子（15–30s）

「XOR 只有 4 个样本，但单层感知机学不会——我们用纯 C++ 手写一个能学会的小网络。」

## 第一段：直觉

- 为什么需要非线性隐藏层
- 训练闭环：前向 → 损失 → 反向 → 更新

## 第二段：结构

对照仓库模块：

- `Matrix`：数值底座
- `Layer`：`XW + b` + 激活
- `Mlp`：叠层 + 损失梯度入口

点出两个易错点：

1. MSE 梯度是 `(ŷ − y) / N`，不是乱做矩阵乘
2. 回传输入梯度时要用 **更新前** 的 `W`

## 第三段：实验演示

```bash
make run
```

指出日志里的 `loss` / `acc`，以及推理表里四个样本的 raw / 0-1 预测。

- 收获：你已经拥有一条可运行的学习闭环
