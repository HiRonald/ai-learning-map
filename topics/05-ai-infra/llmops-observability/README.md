## 要解决什么问题

模型上线后如何知道「慢了、贵了、答歪了」？日志、追踪、评估回流在链路里站哪一环？

## 直觉

训练有 loss 曲线；线上需要 **请求级可观测性**：延迟、token 成本、工具失败率、人工/自动评测抽样。没有这一环，RAG/Agent 只能「感觉在跑」。

## 结构 / 公式
