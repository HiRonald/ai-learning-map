# LLM 生命周期：预训练 / SFT / 对齐

> 状态：draft · 轨道：Transformers · 难度：L2

## 要解决什么问题

聊天模型不是「训一个分类器」那么简单。从海量文本预训练，到听话好用，再到推理时「多想一会儿」，中间大致经过哪些阶段？

## 直觉

**预训练**学世界与语言的统计结构；**SFT** 学会按指令答题的格式；**对齐**（RLHF/同类方法，概念级）让行为更符合人类偏好与安全约束。

近年还有第四段叙事：**test-time compute / reasoning**——不靠再训一个更大底座，而在推理时多花算力（长思维链、搜索式解码等），换更难任务上的正确率。这会改变 [Agent](../../04-llm-apps/agents-basics/) 的形态：有些多步链被「单次深推理」部分替代，有些仍要工具循环。

## 结构 / 公式

1. 三阶段流水线简图：预训练 → SFT → 对齐；每阶段「数据长什么样、优化什么目标」。
2. 适配旁路：全量微调 vs [PEFT](../efficient-finetune/)（落地常走后者）。
3. Test-time compute：训练时算力 vs 推理时算力的权衡；与「更大模型」不是同一旋钮。
