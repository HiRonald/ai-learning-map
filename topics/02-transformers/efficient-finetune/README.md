# 高效微调：LoRA / PEFT 直觉

> 状态：draft · 轨道：Transformers · 难度：L2

## 要解决什么问题

全量微调大模型太贵。如何只训少量参数，就把基座适配到自己的任务或风格？

## 直觉

冻结大权重，在关键层插入小的可训练旁路（如 LoRA 低秩增量）。效果常「够用」，成本降一个数量级以上——这是工业落地最常见的微调形态。

## 结构 / 公式

（写作中）`W' ≈ W + ΔW`，`ΔW` 低秩分解示意；和全量 SFT 的取舍。
